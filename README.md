# 🐧 Penguin Species Classification (Machine Learning)

A multi-class classification project predicting penguin species using biological features from the Palmer Penguins dataset.

## 🔧 Tech Stack
- Python
- scikit-learn
- NumPy / Pandas
- Matplotlib / Seaborn

## 📌 Features
- Logistic Regression classifier
- Linear SVM model
- Exploratory Data Analysis (EDA)
- Feature engineering and visualization
- Decision boundary interpretation
- Model evaluation and comparison

## 📊 Results
- Achieved 95%+ accuracy on penguin species classification
- Identified top predictive features through visualization
- Compared Logistic Regression vs. SVM performance

## 📁 Repository Structure
penguin-classification-ml-project/
- penguin_project.ipynb
- README.md            
- data/                

## ▶️ How to Run

1. Install dependencies (in a terminal):
   pip install numpy pandas matplotlib seaborn scikit-learn jupyter palmerpenguins

2. Launch Jupyter Notebook:
   jupyter notebook penguin_project.ipynb

3. Run all cells in the notebook to reproduce the analysis and results.
